# 主界面动态背景提示词

以下提示词都以 `C:/Users/jay/Desktop/主镜头.png` 作为参考图，目标是生成同一镜头下的连续帧。  
建议统一要求：`16:9 横版，镜头锁定，构图锁定，木屋结构锁定，树木位置锁定，乌鸦总体分布锁定，雾气和火光只允许微小变化，禁止镜头位移，禁止新增角色，禁止卡通化，禁止高魔炫技效果。`

## 通用负面约束

```text
不要改变木屋外形，不要改变森林布局，不要改变树干和树枝位置，不要让乌鸦大规模瞬移，不要出现新的怪物或人物，不要把黑影做成清晰人物，不要夸张特效，不要雷电，不要蓝色魔法光，不要让门后出现室内细节，不要让画面变得热闹，不要改变参考图的透视和镜头焦距。
```

## 主界面暗化版基底图

```text
基于参考图生成同一场景的主界面背景图。保持木屋、树木、乌鸦、雾气、火光与整体构图完全一致，在原图基础上增加更压抑、更阴冷的主界面暗化滤镜。画面边缘被更深的黑暗吞没，中央木屋区域仍可辨认，窗内暖光被压暗但保留微弱呼吸感，整体像一个可交互游戏开始界面而不是插画海报。风格保持写实偏绘画、阴森、克制、低饱和、冷雾、朴素诡异。不要引入新物体，不要修改木屋门的开合状态。
```

## 待机动画

### 1. 待机基础帧

```text
基于参考图生成同一场景的稳定基础帧。保持木屋、树木、乌鸦位置、雾气、火光和构图与参考图一致。不要出现明显运动，只保留安静、阴森、压抑的主界面背景效果。整体作为待机动画的第一帧，镜头完全静止，木屋门保持关闭，窗内火光微弱但稳定，乌鸦全部停驻，没有飞行动作。
```

### 2. 待机轻微变化帧

```text
基于参考图生成同一场景的连续帧。保持镜头、构图、木屋和森林完全不变，只做非常轻微的动态变化：少量乌鸦轻微转头或微微抬翅，窗内火光轻轻晃动，雾气只有极弱的流动感。整体变化幅度必须非常小，像主界面背景在低频率呼吸一样。不要让乌鸦飞走，不要改变屋子结构，不要增加新的叙事信息。
```

### 3. 窗边黑影帧

```text
基于参考图生成同一场景的连续帧。保持镜头和构图完全不变，木屋和森林不变，乌鸦大体保持原位。只在其中一个亮着火光的窗户内，短暂出现一个模糊、难以辨认的黑色影子从窗前掠过，像屋内有某种存在移动。黑影必须模糊、短暂、压抑，不能清晰到像具体人物，也不能抢走整张图的主导权。火光仍然存在，但略微受扰动，像被黑影遮挡了一瞬间。
```

### 4. 待机回落帧

```text
基于参考图生成同一场景的连续帧。保持所有结构不变，让窗内的黑影消失，火光微微回摆后重新稳定，乌鸦恢复低频静止状态，只有个别乌鸦有轻微姿态差异。整体回到安静、诡异、压抑的待机状态，像什么都没发生过，但气氛比第一帧更令人不安。
```

## “开始游戏”动画

### 帧 1：初始状态

```text
基于参考图生成开始游戏动画的第一帧。保持场景完全一致：木屋门关闭，窗户有微弱暖光，乌鸦停在屋顶和树枝上，森林被雾气包围，整体安静阴森。所有元素稳定，像等待玩家按下开始按钮的前一秒。
```

### 帧 2：门开一条缝

```text
基于参考图生成开始游戏动画的第二帧。保持镜头、构图、木屋和森林完全不变，只让木屋正门缓缓打开一条狭窄缝隙。门内不是暖光，而是一片纯黑、深不见底的黑暗，像屋内没有任何光线。乌鸦暂时仍停在原处，但整体气氛开始绷紧。不要改变窗户火光位置，不要让门后的黑暗出现任何内部细节。
```

### 帧 3：乌鸦开始受惊

```text
基于参考图生成开始游戏动画的第三帧。保持镜头和场景布局完全一致，让木屋正门打开到大约三分之一，门内仍然是纯粹的漆黑深渊。靠近木屋屋顶和门前树枝的少数乌鸦开始受惊，表现出准备起飞的姿态，例如翅膀半张开、身体抬起，但大多数乌鸦还未离开停驻位置。整体保持压抑，不要做成动作片式夸张爆发。
```

### 帧 4：门继续打开，乌鸦飞起

```text
基于参考图生成开始游戏动画的第四帧。保持同一镜头和构图。木屋正门打开到接近一半，屋内仍是一片吞噬光线的纯黑。大量停在屋顶和近处树枝上的乌鸦振翅飞起，画面中出现一些乌鸦离开停驻点的动态姿态和少量运动残影，营造被惊动后突然散开的效果。森林和木屋本体不要改变，黑暗必须仍是画面最危险的来源。
```

### 帧 5：门几乎全开

```text
基于参考图生成开始游戏动画的第五帧。木屋正门几乎完全打开，屋内是极其浓重的黑暗，没有任何内部细节，也没有暖光。大部分乌鸦已经从屋顶和近处树枝飞散，只剩少量正在掠过画面的黑色羽翼和模糊残影。木屋外部结构、森林、雾气和窗内原有微弱火光仍保持参考图逻辑，但门后的黑暗现在成为视觉中心，像在无声地邀请玩家进入。
```

### 可选帧 6：进入前的停顿

```text
基于参考图生成可选的过渡停顿帧。保持门接近全开，屋内仍是绝对黑暗，乌鸦大多已经飞离，只留下极少数远处剪影。镜头不动，森林和木屋结构不变，让整个画面短暂停滞，像玩家即将被吸入门后的黑暗。不要加入角色，不要让门后出现任何可辨认空间。
```
